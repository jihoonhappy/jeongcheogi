# 정보처리기사 필기 트레이너

빌드 도구도 서버도 없이 동작하는 학습 앱. GitHub Pages에 올리면 PC·태블릿·휴대폰 어디서나 같은 주소로 접속하고, **홈 화면에 설치해 비행기 모드에서도** 쓸 수 있습니다.

```
index.html              앱 본체
manifest.webmanifest    PWA 설치 정보
sw.js                   오프라인 캐시 서비스 워커
icon-192.png            앱 아이콘
icon-512.png
.nojekyll               GitHub Pages 처리 우회
data/
  bank.js               문제은행 로더
  subject1.js           1과목 소프트웨어 설계        100문항
  subject2.js           2과목 소프트웨어 개발        100문항
  subject3.js           3과목 데이터베이스 구축       25문항
  subject4.js           4과목 프로그래밍 언어 활용    26문항
  subject5.js           5과목 정보시스템 구축관리    100문항
```

## 1. GitHub Pages에 올리기

```bash
git init
git add .
git commit -m "정보처리기사 필기 트레이너"
git branch -M main
git remote add origin https://github.com/<사용자명>/<저장소명>.git
git push -u origin main
```

저장소 **Settings → Pages → Source: Deploy from a branch → Branch: main / (root)** 저장.

1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 로 접속됩니다.

> Pages는 무료 플랜에서 Public 저장소만 지원합니다. Private으로 두려면 로컬에서 `index.html`을 직접 열어도 되지만, 이 경우 오프라인 캐시(서비스 워커)는 동작하지 않습니다.

## 2. 휴대폰에 설치하기

| 기기 | 방법 |
|---|---|
| iPhone·iPad | Safari로 접속 → 공유 버튼 → **홈 화면에 추가** |
| Android | Chrome으로 접속 → 메뉴 → **앱 설치** |
| PC | Chrome 주소창 오른쪽 설치 아이콘 |

설치 후에는 주소창 없는 전체 화면으로 실행되고, **네트워크가 없어도 그대로 열립니다.** 문제은행 전체가 기기에 캐시되기 때문입니다.

## 3. 학습 모드

| 모드 | 내용 |
|---|---|
| **오늘의 복습** | 간격 반복 일정상 오늘 복습해야 할 문항만 자동 소집 (최대 40) |
| **약점 집중** | 정답률이 낮고 오답이 많은 순으로 최대 30문항 |
| **과목 학습** | 선택한 과목에서 무작위 출제, 한 문제씩 즉시 채점 + 해설 |
| **고빈도 집중** | 출제 빈도 A등급 문항만 |
| **실전 모의고사** | 과목당 20문항 총 100문항, 150분 타이머, 일괄 채점 + 과락 판정 |

보기 순서는 **매번 무작위로 섞입니다.** 정답을 번호 위치로 외우는 것을 막기 위해서입니다.

## 4. 학습 효과 장치

**간격 반복 (Leitner 5단계)**
문항마다 복습 단계 1~5를 관리합니다. 맞히면 단계가 오르고 다음 복습일이 **1 → 2 → 4 → 8 → 16일**로 벌어집니다. 틀리면 단계가 1로 떨어지고 그날 복습 큐에 다시 들어갑니다.

**공부 흔적** — 최근 12주 히트맵, 연속 학습일, 누적 문항, 최근 세션 12건 기록

**복습 흔적** — 문항별 시도/정답/오답과 현재 단계를 해설 아래에 항상 표시

**약점 진단** — 자주 틀리는 문제 TOP 20, 토픽별 정답률 순위, 과목별 숙련도 게이지

**과락 판정** — 모의고사에서 한 과목이라도 40% 미만이면 평균과 무관하게 경고 (실제 시험 규칙과 동일)

## 5. 기기 간 기록 이동

학습 기록은 브라우저 localStorage에 저장되므로 **기기별로 분리**됩니다. 옮기려면 통계 화면의 **기기 간 이동·백업**에서

1. 기존 기기 → `현재 기록 내보내기` → 코드 전체 복사
2. 새 기기 → 코드 붙여넣기 → `불러오기`

자동 동기화가 필요하면 Firebase 연동이 필요합니다.

## 6. 문제 추가하기

해당 과목 파일에 객체를 덧붙이면 앱이 자동 인식합니다.

```js
{
  id: 5101,             // 고유 번호 (과목별 대역: 1xxx~5xxx)
  s: 5,                 // 과목 1~5
  t: "암호화",           // 토픽 — 약점 분석 단위
  f: "A",               // 빈도 A(최다) / B(자주) / C(가끔)
  q: "문제 지문",         // \n 으로 줄바꿈 가능
  c: ["보기1","보기2","보기3","보기4"],
  a: 2,                 // 정답 인덱스 (0부터)
  e: "해설"
}
```

**중요:** 문제은행을 수정한 뒤에는 `sw.js`의 `CACHE = "jbg-v1"` 버전을 `jbg-v2`처럼 올려야 설치된 기기에 새 문항이 반영됩니다. 캐시가 갱신되지 않으면 예전 문제만 계속 나옵니다.

```bash
git add . && git commit -m "문제 추가" && git push
```

기존 학습 기록은 문항 id 기준으로 유지됩니다.
